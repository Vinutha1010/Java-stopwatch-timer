# ⏱️ Java Stopwatch & Timer Sidebar

A lightweight, frameless, and floating desktop timer application built with **Java Swing**. Designed as a unobtrusive sidebar widget to help track productivity while working or studying.

![Java](https://img.shields.io/badge/Java-17%2B-orange?style=flat-square&logo=openjdk)
![License](https://img.shields.io/badge/License-MIT-blue?style=flat-square)

---

## ✨ Features

- **Dual Modes:** Toggle seamlessly between **Stopwatch** (count up) and **Timer** (countdown).
- **Floating Sidebar:** Always-on-top window that stays pinned to the side of your desktop.
- **Stopwatch Aesthetic:** Custom-drawn frameless window styled like a classic pocket stopwatch.
- **Dynamic Themes:** Includes 8 color schemes (*Cyberpunk, Dracula, Emerald, Midnight, Nord, Sunset, Amethyst, Mocha*).
- **Frameless Drag-and-Drop:** Reposition anywhere on screen by dragging the window body.
- **Custom Window Controls:** Custom vector minimize (`─`) and exit (`✕`) buttons that render cleanly across all operating systems.
